# CPU predictive inference. Part of the SUPPORTED runtime.
#
# OpenVINO on CPU is the required baseline for the predictive layer. The NPU
# is optional hardware and measured SLOWER for this workload (CPU 0.121 ms
# vs NPU 0.376 ms) — it is spare capacity, not acceleration. No CUDA is
# involved at any point: the RTX 5090 is reached through LM Studio's HTTP
# API, not through this process.
#
# Install:
#     pip install -r requirements-inference.txt
#
# NUMPY IS DELIBERATELY NOT PINNED AGAIN HERE. It is pinned once, in
# requirements.txt, and a second pin site is somewhere for the two to drift
# apart. But openvino only constrains numpy to <2.6.0, so installing this
# file ALONE would happily resolve numpy 2.x and silently replace the
# numerical foundation the trading system is tested against — which is the
# exact accident the pin exists to prevent. Hence the include: inference
# runs inside JARVIS, so it never wants the runtime absent anyway.
-r requirements.txt

openvino==2026.3.0
